# DEV-JOURNAL — fx_python

## Статус
Готово. Десктопная версия «Охота на лис» (Tkinter) с сохранением/загрузкой.

## Решения
- 2026-08-24: стек — Tkinter (встроен в Python 3.14, Tcl/Tk 9.0).
- Логика отделена от GUI (`game.py` + `main.py`) — логика покрыта тестами.
- Формат сохранения: JSON, версия 1 (поле `version` для совместимости).

## Проверка (2026-08-24)
- Тесты логики: 11/11 зелёные (создание, пеленг, серые линии, победа,
  поражение, save/load roundtrip, неверная версия, max_moves).
- Smoke-тест GUI: меню, доска, ход + перерисовка — ок.
- Исправление: клетки 15×15 были прямоугольными (Tk-кнопки: width/height в
  символах/строках). Переведено на Canvas — клетки рисуются прямоугольниками
  cell×cell в пикселях, гарантированно квадратные (проверено: 414×414 и
  510×510 для полей 9×9 и 15×15). Клик по координатам, выход за поле
  игнорируется.

## Изменения (2026-08-24)
- Лимит ходов: вместо 100 — `size² − 1` (свойство `FoxGame.max_moves`):
  8×8→63, 9×9→80, 10×10→99, 15×15→224. Сообщение и статистика обновлены.
- Курсор над клетками поля — «прицел» (`cursor="target"`: перекрестие с
  кружком). Примечание: Tk 9.0 на Windows НЕ поддерживает кастомные
  XBM/PhotoImage-курсоры (проверено) — используется встроенный "target".
- Защита `_update_foxes_options` от trace вне меню.

## Запуск
`python main.py` — из папки fx_python.
