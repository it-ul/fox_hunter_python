# 🦊 Охота на лис — десктоп (Python / Tkinter)

Десктопная версия игры «Охота на лис»: лисы спрятаны на поле, клик по клетке
показывает **пеленг** — сколько лис стоит на той же вертикали, горизонтали
и обеих диагоналях. Пеленг 0 закрашивает серым все линии клетки (там лис нет).

## Возможности

- **SDI-интерфейс**: одно окно в три колонки — описание слева, игровое поле
  в центре, управление и информация справа.
- Поля 8×8, 9×9, 10×10, 15×15; лисы 5…размер поля.
- Лимит ходов: размер поля в квадрате минус 1 (9×9 — 80, 15×15 — 224).
- **Сохранение и продолжение игры**: сохранение всего состояния (включая пометки
  и протокол) в JSON-файл.
- **ПКМ по клетке** — пометить её серым (как пеленг 0), повторный ПКМ снимает.
- **Координаты поля**: слева цифры (снизу вверх), снизу латинские буквы.
- **Панель управления**: все кнопки, информация о состоянии и протокол ходов
  («1. e4 — пеленг 2, лиса: нет»).
- **Описание и правила** — в левой колонке, всегда на виду.
- **Результат игры** выводится над полем, поле остаётся на последнем ходе.
- Иконка лисы в клетках и в заголовке окна, курсор-прицел над полем.
- Клетки рисуются на Canvas — квадратные при любом размере.

## Запуск из исходников

Требуется Python 3.10+ (используется только стандартная библиотека):

```
python main.py
```

## Сборка .exe

```
pip install pyinstaller
python -m PyInstaller FoxHunter.spec
```

Готовый файл: `dist\FoxHunter.exe`.

## Тесты

```
python test_game.py
```

## Структура

- `main.py` — главное окно (поле, координаты, баннер результата)
- `control_panel.py` — окно управления (кнопки, информация, протокол)
- `game.py` — логика игры (`FoxGame`), включая save/load, пометки, протокол
- `assets/fox.png` — иконка лисы
- `test_game.py` — тесты логики
- `SPEC.md`, `DEV-JOURNAL.md`, `ToDo.md` — ТЗ, журнал, список доработок
